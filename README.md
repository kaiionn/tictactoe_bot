# Крестики-нолики в Telegram

Бот с игрой в крестики-нолики: партия с компьютером (минимакс + альфа-бета)
или с другом по коду приглашения. Доска — инлайн-кнопки 3×3, счёт,
статистика и история партий сохраняются в `game_data.json`.

## Файлы

| Файл | Что делает |
|---|---|
| `bot.py` | Telegram-бот: экраны, кнопки, ходы (aiogram 3) |
| `game.py` | Игровая логика: поле, правила, ИИ — без ввода-вывода |
| `storage.py` | Игроки, статистика, история (атомарная запись JSON) |
| `tests/` | Юнит-тесты (`python -m unittest discover -s tests`) |
| `game_data.json` | Данные игроков, создаётся автоматически, **в git не попадает** |

## Запуск

```powershell
pip install -r requirements.txt

# токен от @BotFather
$env:TELEGRAM_BOT_TOKEN = "123456:ABC-DEF..."
python bot.py
```

В `cmd.exe`: `set TELEGRAM_BOT_TOKEN=123456:ABC-DEF...` — или передайте токен
первым аргументом: `python bot.py 123456:ABC-DEF...` (так токен остаётся
в истории shell и в списке процессов — надёжнее переменная окружения).

## Как играть

- **🤖 Против компьютера** — вы играете за ❌, компьютер за ⭕.
  Первый ход после каждой партии достаётся сопернику.
- **👥 С другом** — бот выдаёт код приглашения; второй игрок пишет
  `/join КОД` (в личке с ботом или в группе). Доска появится у обоих.
- Кнопки: `1–9` — ход, `🔁 Ещё партия` / `🔄 Заново` — новая партия,
  `⏹ Меню` — выйти из партии.

Команды: `/menu` — главное меню, `/join КОД` — присоединиться, `/help` — справка.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

Тесты не ходят в сеть и не трогают `game_data.json`: каждый тест работает
с временным файлом во временном каталоге. То же самое гоняет CI
(`.github/workflows/ci.yml`) на Python 3.10 и 3.13.

## Данные и их защита

- `game_data.json` содержит имена и Telegram ID реальных игроков, поэтому
  он в `.gitignore` и не должен попадать в коммиты и публичные репозитории.
  Регулярно делайте резервную копию — это единственный носитель статистики.
- Запись атомарная (`*.tmp` → `os.replace` + `fsync`) и выполняется под
  межпроцессной блокировкой: второй экземпляр бота или ручная правка файла
  не затирают чужие записи — правка подхватывается при следующем сохранении.
- Если файл повреждён, он не стирается молча, а откладывается в
  `game_data.json.corrupt-<дата>` с записью ошибки в лог.

## Известные ограничения

- **ИИ не ошибается.** Он считает все варианты (минимакс + альфа-бета) и
  выбирает случайным образом только среди равных по силе ходов — поэтому
  партия чаще всего заканчивается вничью.
- Наследование старых консольных аккаунтов идёт по совпадению имени
  (однократно, с пометкой `claimed_by` в файле). Паролей в боте больше нет,
  проверить владельца нечем — осознанный компромисс миграции.
- Активные партии и коды приглашений живут в памяти: после перезапуска
  бота открытые доски закрываются (история и статистика при этом целы).
  Простаивающие дольше 2 часов партии закрываются автоматически.

## Игроки

Авторизация — по Telegram ID, пароль не нужен. Старые консольные аккаунты
из `game_data.json` сохраняются: при первом входе пользователя с совпадающим
именем их статистика переходит ему, запись помечается `claimed`/`claimed_by`,
связанные партии привязываются к его Telegram ID (их больше не найдёт
совпавший по имени посторонний), а неиспользуемые `salt`/`hash` удаляются.
